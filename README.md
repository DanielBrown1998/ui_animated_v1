## ✨ Destaques

| Feature | Descrição |
|---------|-----------|
| 🎨 **Glassmorphism** | Design moderno com efeitos de vidro |
| 🔄 **3D Viewer** | Modelos GLB interativos |
| 📱 **AR** | Realidade Aumentada |
| 🎬 **Animações** | `flutter_animate` + `CustomPainter` |
| 🏁 **Nürburgring** | Pista animada com path metrics |
